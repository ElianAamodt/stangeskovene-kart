# Stangeskovene kart

Felles, nettleserbasert kart- og filtermotor for Stangeskovenes Webflow-nettsted.

Dette repoet inneholder bare distribuert JavaScript og teknisk dokumentasjon. CMS-innhold, kontaktdata og redaksjonelle data ligger i Webflow.

## CDN

```html
<script defer src="https://cdn.jsdelivr.net/gh/ElianAamodt/stangeskovene-kart@main/dist/stangeskovene-map.js"></script>
```

Den første versjonen etablerer en trygg global modul. Kartlag og CMS-adapter legges til i fase 4.
